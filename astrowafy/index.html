01 / CONCEPT & MOTIVATION

Democratizing Astronomical Discoveries

NASA's Astronomy Picture of the Day (APOD) represents one of the most comprehensive public scientific archives on Earth. However, native access is constrained by legacy website layouts and lack of multi-language accessibility for regional science students.

AstroWafy was engineered to bridge this gap: a streamlined, dark-mode cosmic viewport pairing high-resolution space photography with client-side localization into Bengali, interactive date-travel controls, and direct image acquisition.

02 / DATA INTEGRATION

REST Protocol Handling & Temporal Queries

The client orchestrates asynchronous HTTP requests directly to the NASA planetary endpoint using API key authentication. A native date selection calendar allows users to travel through archival records dating back to APOD's launch in 1995.

03 / LOCALIZATION ARCHITECTURE

Bilingual Translation Pipeline & In-Memory Cache

  • Race Condition Guards: Fast date switching can cause asynchronous translation callbacks to resolve out of order. Validation checks verify that incoming data matches active date states before manipulating the DOM.
  • In-Memory Cache Hash: Translated scientific terminology is mapped to date keys (YYYY-MM-DD_bn), eliminating redundant network calls when toggling repeatedly between English and Bengali.

04 / ASSET EXTRACTION

Binary Blob Streaming & HD Downloads

Browsers normally open external image links in a new tab instead of saving them locally due to cross-origin headers. AstroWafy solves this through a custom download pipeline:

Fetch Binary Stream -> Convert to Blob -> Create Object URL -> Inject Anchored Download

05 / RETROSPECTIVE

Engineering Takeaways

Building AstroWafy demonstrated the importance of designing resilient user experiences around third-party rate-limited APIs with graceful error state handling and smooth CSS transitions.
