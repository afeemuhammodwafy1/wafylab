HOW THE LAB WORKS

Build it.
Break it.
Understand it.

01

Question

Start with something worth solving, automating, understanding or simply trying.

02

Prototype

Build the smallest useful version. Constraints are part of the experiment.

03

Stress test

Find the weak points — technical, architectural, UX or operational.

04

Document

Keep the decisions, mistakes and lessons instead of pretending the first version was perfect.

ABOUT THE LAB

A working space for building, testing, and learning.

Wafy Lab is the independent project laboratory of Afee Muhammod Wafy. It documents the software behind the experiments: full-stack web applications, developer tools, web security projects, API integrations, prototypes, and the lessons that come from shipping them.

The lab complements the professional portfolio by focusing on how things are built rather than only presenting finished work. Each build is a record of decisions, implementation challenges, testing, and technical growth.

FAQ

Questions about Wafy Lab.

What is Wafy Lab?

Wafy Lab is Afee Muhammod Wafy's independent space for software projects, experiments, prototypes, technical notes, and lessons learned while building.

What technologies are used in Wafy Lab projects?

Projects explore technologies including Python, Flask, JavaScript, Next.js, HTML, CSS, REST APIs, OWASP-oriented web security, Chart.js, and the NASA APOD API.

Where can I find the source code?

Open-source projects and source repositories are linked from their individual build entries and GitHub profile.
